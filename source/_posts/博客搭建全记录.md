> 道阻且长，行则将至

历时数日，我的个人博客终于搭建完成。写这篇文章，既是对这段经历的记录，也希望能给想要搭建博客的朋友一些参考。

## 写在前面

一直想拥有一个属于自己的博客，用来记录学习心得、技术笔记和生活点滴。之前也尝试过一些方案，但总是因为各种原因搁置。这次终于下定决心，从零开始搭建一个完整的博客系统。

## 技术选型

经过调研，最终选择了以下技术栈：

- **Hexo 8.1.1**：快速、简洁且高效的静态博客框架
- **Anzhiyu 主题**：一款美观大气的 Hexo 主题
- **GitHub Pages**：免费托管博客

选择 Hexo 的原因很简单：它基于 Node.js，拥有丰富的主题和插件生态，而且完全静态化，访问速度快，部署也方便。

## 搭建过程

### 1. 环境准备

在开始之前，需要确保本地安装了以下工具：

- **Node.js**：Hexo 基于 Node.js 开发，建议使用 LTS 版本
- **Git**：用于版本控制和部署

可以在终端输入以下命令验证是否已安装：

```bash
node -v
npm -v
git --version
```

### 2. 初始化 Hexo 项目

全局安装 Hexo CLI：

```bash
npm install -g hexo-cli
```

初始化博客项目：

```bash
hexo init my-blog
cd my-blog
npm install
```

启动本地服务器预览：

```bash
hexo server
```

现在访问 `http://localhost:4000` 就能看到默认的博客页面了。

### 3. 安装主题

安知鱼主题是我偶然发现的一款非常棒的主题，界面简洁美观，功能也很丰富。

安装主题：

```bash
git clone https://github.com/anzhiyu-c/hexo-theme-anzhiyu.git themes/anzhiyu
```

在 `_config.yml` 中修改主题配置：

```yaml
theme: anzhiyu
```

同时还需要安装主题所需的依赖：

```bash
npm install hexo-renderer-pug hexo-renderer-stylus
```

### 4. 配置博客

主要配置文件有两个：
- `_config.yml`：Hexo 站点配置
- `themes/anzhiyu/_config.yml`：主题配置

以下是一些关键配置：

```yaml
# 站点信息
title: Echo's Blog
description: 道阻且长，行则将至
author: Echo
language: zh-CN

# URL 配置
url: https://yourname.github.io/repo
root: /repo/

# 部署配置
deploy:
  type: git
  repo: https://github.com/yourname/repo.git
  branch: gh-pages
```

### 5. 安装必要的插件

根据需求，我安装了以下插件：

```bash
# Git 部署插件
npm install hexo-deployer-git

# APlayer 音乐播放器
npm install hexo-tag-aplayer

# 信封评论样式
npm install hexo-butterfly-envelope
```

### 6. 部署上线

生成静态文件：

```bash
hexo clean
hexo generate
```

部署到 GitHub Pages：

```bash
hexo deploy
```

也可以使用 npm 脚本：

```bash
npm run deploy
```

## 主题定制

安知hiu 主题提供了丰富的定制选项，包括：

- 顶部导航栏定制
- 侧边栏社交链接
- 音乐播放器集成
- AI 摘要功能
- 评论区集成

具体的配置可以参考主题的官方文档进行调整。

## 后续计划

博客搭建完成只是一个开始，后续计划：

- 持续更新高质量的技术文章
- 添加更多的个性化功能
- 优化 SEO 收录
- 考虑接入域名绑定

## 总结

整个搭建过程比想象中要顺利得多。Hexo 的文档非常完善，遇到问题基本都能找到解决方案。安知鱼主题的作者也提供了详细的配置教程节省了不少时间。

如果你也想拥有一个自己的博客，不妨试试 Hexo。过程中的每一次配置和调整，都是学习和成长的过程。
